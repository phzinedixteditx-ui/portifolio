# Matheus Felipe — Estúdio Digital | Portfólio Autoral

Portfólio interativo de alta performance desenvolvido com design limpo inspirado na Apple e micro-interações fluidas a 60/120 FPS.

Apresentação com 3 sites reais funcionando 100% ao vivo dentro de molduras responsivas:

1. **Monarch Superyachts**: Experiência cinematográfica para o mercado náutico de ultra-luxo com preloader editorial e tipografia serifada.
2. **Nexa Telecom**: Provedor de fibra óptica com foguete de partículas 3D renderizado em tempo real via Three.js e rolagem ultrafluida.
3. **Vanice Private Estates**: Portfólio imobiliário autoral de coberturas e mansões com entrada sensorial e concierge privativo.

---

## 🛠 Tecnologias & Performance

- **HTML5 & CSS3 Moderno**: Variáveis CSS, Glassmorphism, tipografia fluida (`clamp`), molduras responsivas macOS / iPhone.
- **Lenis Smooth Scroll Engine**: Rolagem aveludada sincronizada com aceleração de hardware.
- **Three.js & WebGL**: Renderização de partículas com otimização via `IntersectionObserver` para economia de GPU.
- **Touch & Mobile Protection Engine**: Controle de rolagem nativo em smartphones com barreira inteligente contra captura de toque.
